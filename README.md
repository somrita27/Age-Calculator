# Age Calculator
A responsive and interactive Age Calculator built using HTML, CSS, and JavaScript.
The application calculates a person's exact age in **years, months, and days** based on their date of birth and a selected current date.

## Live Demo
[Visit Age Calculator](https://age-calculator-eta-mauve.vercel.app)

## Features
- Calculate age in years, months, and days
- Automatically sets the current date
- Allows users to edit the current date
- Calendar-based age calculation
- Prevents invalid date ranges
- Responsive design
- Modern gradient and glass-style interface
- Works directly in the browser without any backend

## Technologies Used
- HTML5
- CSS3
- JavaScript
